## Фіксація однієї фінальної конфігурації

Final calibration використовує лише дев'ять INNER held-out наборів: raw scores повторної pair_id усереднюються один раз, кожна пара має однакову вагу. Fold-пороги не усереднюються. Outer scores не використано для нового добору параметрів. Selection-метрики не є незалежною якістю.

Калібровка охопила 1203 унікальних пар. Після неї виконано один full-TRAIN fit; параметри й пороги збережено у frozen_configuration.json.

Маскування auxiliary/all_groups: 0/10/20/30/50%, seeds 11/22/33, без зміни outer-порогів. Повні P/R/F1 та confusion counts збережено в missingness_metrics.csv.

Обмеження: TRAIN раніше аналізувався; виключення негативів змінює prevalence; після full-TRAIN refit можуть змінитися IDF/інформативність/шкала LR. Перенесення operating point не виправляється за TEST. Score не є каліброваною ймовірністю. Search Recall@K/Precision@K не вимірювалися.

## Інтерпретація без підбору після результатів

Corrected F1=0.7897 не перевищує Fixed=0.7935, v1=0.7922 або Renormalization=0.7910. Порівняно з v1 corrected має два додаткові TP, але сім додаткових FP; hard-negative FPR становить 0.8311 проти 0.8176 у v1. Усунення додатного prior не гарантує вищого Precision або F1, особливо коли кожний метод має свій внутрішньо обраний поріг. Перевага corrected за якістю не встановлена.

Кандидат фіксується через задану методичну корекцію: нульовий prior, відсутність identifier penalty та межу score ≤ coverage. Формула, gamma=1, ручні множники й сітка порогів після нових результатів не змінювалися. Вона не проголошується універсально кращим методом чи доведеною новизною.

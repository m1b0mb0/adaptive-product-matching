# Наукові й технічні обмеження

- Оцінюється одна зафіксована WDC 80cc small → 100un конфігурація.
  Висновки не гарантують перенесення на інші категорії або FPV.
- До цього етапу TRAIN/TUNE/REPORT багаторазово переглядались.
  За локальними артефактами це перше фінальне TEST-оцінювання.
  Запуски поза цим workspace неможливо виключити за локальними файлами.
- Після цього TEST є переглянутим; його результати не можуть бути
  незалежним підтвердженням наступних змін.
- Відкидання crossing negatives у development змінило prevalence;
  full-TRAIN refit змінює IDF/інформативність/шкалу LR.
  Пороги перенесено як зафіксовано, без корекції за TEST.
- Official labels не виправляються й підозрілі пари не видаляються.
- Scores евристик не є каліброваними ймовірностями; зовнішня калібрація
  LR не доведена. Ручна reliability не є доведеною якістю джерел.
- Identifier є евристикою з title, не верифікованим manufacturer MPN.
  Title/identifier мають спільний бюджет; суперечності модифікацій
  і різні формати кодів залишаються обмеженнями.
- Маски симулюють пропуски на offer level. Це не встановлений механізм
  реальної втрати даних. За rate r порівняння двох доступних endpoints
  може втратитися з імовірністю 1-(1-r)^2.
- Три mask seeds повторюють ті самі товари; sample SD не є confidence
  interval і не доводить статистичної значущості відмінностей.
- Основна метрика — clean binary F1; hard-negative FPR і Recall/Precision
  описують trade-offs. Найвище виміряне F1 не означає доведеної
  універсальної переваги чи фундаментальної наукової новизни.
- Pairwise P/R/F1 не вимірюють candidate recall або end-to-end
  Recall@K/Precision@K. Для останніх потрібна вичерпна query relevance
  розмітка. Непідтверджені FPV labels не використовуються.
- Рекомендація для прототипу є рішенням за результатами benchmark
  з цими обмеженнями. Default CLI у цьому етапі не змінюється.

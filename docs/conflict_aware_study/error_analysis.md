# Аналіз спрацьовувань і ризику Recall

Оцінки стосуються незмінених official labels. Назви прочитано локально;
вебсторінки та manufacturer catalogs не перевірялися. Semantic review
є пояснювальною анотацією цього дослідження, не новими gold labels.

## Схожі назви різних модифікацій

- 10999896#3762458: Hikvision DS-7204HQHI-K1 / DS-7216HQHI-K1.
  Назви явно містять різні коди та 4/16 каналів; обидва baseline мають FP.
  Identifier Jaccard=0 вже враховано Renorm, але цього недостатньо.
- 11409646#29553137: Corsair ML120 120mm / ML140 140mm.
  Це правдоподібний конфлікт моделі та діаметра за назвами; common FP.
- 1136383#41520329: Evans EC2 14 inch / 13 in. — common FP.
- 46010816#87459276: Dymo 9mm / 12mm, також різний колір; common FP.

Розбіжність числового параметра не є незалежним новим свідченням
у всіх випадках: ML120/ML140 одночасно кодують розмір у model token.
Неперевірене додавання двох штрафів повторно рахувало б цю інформацію.

## Positive-контрприклади до identifier penalty

63 official positives мають disjoint identifier; 58 з них —
правильні позитивні рішення Renorm.

- 12243414#80102860: Canon CLI-251BK XL / 6448B001 (CLI-251XL).
  Схожість model/family та різні рівні кодів; автоматична нерівність
  токенів не підтверджує різні сутності.
- 19042808#12650660: Epson C13T603700 / T6037.
  Повний і скорочений код, а також коди сумісних принтерів у першій назві.
- 21670568#79415655: UVC-G4-PRO / G4-PRO — різний префікс запису.
- 24791295#97940008: Shimano R7000 / RD-R7000 — префікс компонента.
- 1821257#33622216: коди сумісних камер / код кронштейна.
  Код не завжди описує товар, який продається.

Навіть 144 disjoint-singleton пари містять 28 positives, з них 24 TP.
Отже вимога «один код з кожного боку» сама по собі проблему не усуває.
Немає підстав трактувати всі ці positives як помилки gold.

## Явні одиниці: роль параметра має значення

Усі 16 різних scalar values з однаковою одиницею переглянуто:

- 13 пар порівнюють за назвами правдоподібно ту саму роль розміру:
  фокусна відстань, розмір вентилятора, барабанної мембрани або ширина стрічки.
  Серед них 12 negatives і 1 positive.
- 3 спрацьовування семантично неоднорідні: ширина Dymo tape /
  підтримуваний radiator size; focal length / audio connector;
  окремий вентилятор / розмір вбудованих вентиляторів корпусу.
  Всі три мають negative gold, але це **не робить механізм порівняння
  одиниць правильним**. Renorm уже класифікує їх як TN.

Positive 3348619#50156673: Fujifilm XF 23mm f/2 / XF 27mm f/2.8.
За назвами є сильна підозра на проблему official label, але його
залишено позитивним. Поточне рішення Renorm — TP. Не можна видалити
цю пару, щоб оголосити size-конфлікт безпечним щодо Recall.

Дві positive-пари мають різні одиниці:
97634734#15774916 — Corsair 140mm / 14cm (можливі еквівалентні величини);
52356483#91126559 — Crucial SSD 2.5 inch / 7mm (form factor / товщина).
Механічна конверсія одиниць виправила б перший випадок, але не вирішила
б проблему різних властивостей у другому.

Відсутність атрибута не є суперечністю. За size missing-one є 33
positives, усі нині TP. Multiple/range/ratio expressions потребують
іншого представлення: scalar parser не повинен перетворювати
24–70mm на однозначне 70mm або 16:9in на розмір 9in.

## Що встановлено й чого не виміряно

Найбільш конкретний size-сигнал охоплює лише 16/1135 пар, причому
повторюються ті самі товари (наприклад Sony SEL50F18F і Corsair ML140).
Це не 16 незалежних типів модифікацій. 12 common FP — лише частина
243 спільних FP. Приклади показують перспективу семантичного
розпізнавання властивості, але не готовність універсального штрафу.

Новий classifier не оцінювався; число виправлених FP/доданих FN та
його Precision/Recall/F1 не визначались. Числа TP at risk не є цими
метриками. Змін рішень немає, бо модифікація не реалізована.
Групове протоколювання і cached-пороги baseline залишено без змін.

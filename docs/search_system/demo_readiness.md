# Готовність до демонстрації

Початковий стан для Task 7.3 — `e1d73f17836d51639479b2bb20a9ff5ac12f46a2`, 661 успішний тест. Після точкових виправлень застосунок пройшов запуск на Windows із чистим середовищем Python 3.12.10, пошук і порівняння на FPV та WDC, відмовостійкі сценарії й історичні перевірки. Блокувальних проблем для описаної демонстрації не виявлено.

## Запуск на Windows

У PowerShell із кореня репозиторію `python --version` має показувати **3.12.10**.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-lock.txt -r requirements-web.txt
.\.venv\Scripts\python.exe -m pip check
.\.venv\Scripts\python.exe -m uvicorn web_app:app --host 127.0.0.1 --port 8000
```

Файли для повної демонстрації:

- `data/external/fpv_motors/fpv_motors_offers_pilot.csv` для FPV.
- `data/external/wdcproducts80cc20rnd000un_valid_small.json.gz` для WDC. Очікуваний SHA-256 записано в [маніфесті](../validation_config.json).
- `docs/final_method/frozen_configuration.json` із Git і оригінальний локальний `data/processed/final_method/frozen_models.joblib` для corrected. [Хеші та вимоги loader](frozen_v1_reproducibility.md)

Для іншого розташування файлів задайте `FPV_CATALOG_PATH` або `WDC_CATALOG_PATH` у тому самому PowerShell, з якого запускаєте сервер. Вебсценарій без TRAIN перевірено з оригінальним bundle та конфігурацією в окремому корені без TRAIN. Без bundle доступні пошук і порівняння через Renormalization та Fixed Weighted. Для відтворення історичних тестів потрібен локальний TRAIN. [Докладні команди](frozen_v1_reproducibility.md)

## Сценарій захисту

1. Відкрийте локальний застосунок. Виберіть «FPV-двигуни» й знайдіть `0802`. Виберіть пропозицію `PH09` від Phoenix Drones. Той самий запис знаходиться за точним `PH09`. [Локальний застосунок](http://127.0.0.1:8000/)
2. Запустіть Renormalization із 20 кандидатами та 5 результатами. Назви формують пул TF-IDF, після чого метод упорядковує кандидатів за доступними ознаками. Оцінка подібності від 0 до 1 визначає порядок. Тотожність потребує окремої перевірки записів.
3. Змініть метод на Fixed Weighted або Adaptive corrected v1, запустіть пошук знову. За потреби увімкніть «Лише з інших джерел» і перевірте, що видача не містить Phoenix Drones.
4. У видачі Renormalization із вимкненим фільтром натисніть «Порівняти» біля `PH02`. Покажіть два записані значення KV, джерело та «Не вказано» в описі. Натисніть «До результатів» і звірте параметри.
5. Поверніться до каталогу й виберіть WDC validation small. Знайдіть `86974759` за ID і повторіть пошук. Покажіть невідоме джерело та відсутність фільтра продавців для цього каталогу.

FPV містить 32 пропозиції. Наявні анотації недостатні для незалежної оцінки якості пошуку, описи в цьому пілоті порожні. Ціни й характеристики належать до моменту збору даних. WDC містить 1 000 пропозицій без магазинів і URL. Раніше використаний validation ділить 500 кластерів із TRAIN. Пошукові метрики стосуються відомих WDC-відповідностей і не встановлюють якість на нових товарних сутностях. [Аудит FPV](../fpv_dataset_audit.md) · [Звіт WDC](wdc_validation_search.md)

Майбутні покращення за потреби демонстрації або дослідження — розкриття наявних діагностик оцінок у вебі, незалежні дані для нових товарних сутностей і окремий наскрізний тест стійкості до пропусків.
